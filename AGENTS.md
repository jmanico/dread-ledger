# Contributor instructions

This is a Markdown prompt library. Keep it focused on the prompts and the
reference material they need; do not add code, bundled examples, or review logs.

Preserve the shared safety contract and separate implementation priority from
logger severity. Verify event meaning, applicability, and coverage against the
target application.
Keep checklist IDs stable, preserve all supplied behaviors, and update
assessment, wave guidance, verification, and handoff links together.

Keep copyable text blocks within 80 columns and check local links after edits.
Use the target application's existing facilities and synthetic test data.
Never commit target reports, real logs, credentials, or personal data.

Jim Manico (`jmanico`) is the maintainer.
